-- BANCO DE DADOS: SUPABASE (POSTGRESQL) - SUPABASE AUTH INTEGRADO

1. Tabela: campeoes (Existente / Seed via Riot Data Dragon)
- id: uuid (PK, default gen_random_uuid())
- nome: text (UNIQUE, NOT NULL)
- criado_em: timestamptz (default now())
- id_riot: text

2. Tabela: usuario_acertos (Progresso por conta logada)
- id: uuid (PK, default gen_random_uuid())
- user_id: uuid (FK -> auth.users.id, ON DELETE CASCADE)
- campeao_id: uuid (FK -> public.campeoes.id, ON DELETE CASCADE)
- descoberto_em: timestamptz (default now())
* Restrição: UNIQUE (user_id, campeao_id)

3. Tabela: conquistas (Catálogo estático de badges da Janna)
- id: text (PK, ex: 'primeira_brisa', 'olho_furacao')
- titulo: text NOT NULL
- descricao: text NOT NULL
- icone: text DEFAULT '✦'
- requisito_tipo: text NOT NULL ('acertos_count' | 'crud_action')
- requisito_qtd: integer NOT NULL DEFAULT 1

4. Tabela: usuario_conquistas (Conquistas desbloqueadas)
- id: uuid (PK, default gen_random_uuid())
- user_id: uuid (FK -> auth.users.id, ON DELETE CASCADE)
- conquista_id: text (FK -> public.conquistas.id, ON DELETE CASCADE)
- desbloqueado_em: timestamptz (default now())
* Restrição: UNIQUE (user_id, conquista_id)
